# CISSP 学習支援システム

> ⚠️ **注意：問題・解説はAI（Claude Code）によって自動生成されています。**
> 内容に誤りが含まれる可能性があります。学習の参考としてご利用ください。
> 正確な情報はISC²の公式資料・テキストをご確認ください。

ISC² CISSP の本番試験形式（CAT）に対応した模擬試験 + 思考パターンを鍛えるシンキングガイドの学習Webアプリです。

## 🌐 オンラインで使う（推奨）

**→ [https://ak69143.github.io/cissp-cat-test/](https://ak69143.github.io/cissp-cat-test/)**

インストール不要。ブラウザからすぐに使えます。

---

## 機能一覧

### 模擬試験

- **CAT形式**：回答に応じて難易度が変化するアダプティブアルゴリズム実装
- **1132問収録**：ドメイン別820問 + 用語問題312問、難易度3段階（Easy / Medium / Hard）
- **2つの試験モード**：模擬試験（CAT）とドメイン別練習
- **用語問題モード**：ドメインごとに重要用語・概念を集中的に練習
- **試験設定**：推定スコア表示・ヒント・解説を個別ON/OFF
- **本番試験モード**：スコア・ヒント・解説をすべて非表示にした厳密なシミュレーション
- **学習記録**：ドメイン別の正答率をブラウザに保存

### シンキングガイド

CISSPで頻出の「考え方のパターン」を集めた参照ガイド。各カードから練習問題をその場で解ける。

| ページ | 内容 | カード数 |
| --- | --- | --- |
| 思考パターン集 | 優先順位・リスク・アクセス制御・暗号など頻出パターン40個 | 40 |
| フレームワーク集 | NIST CSF/RMF、ISO 27001/27005、セキュリティモデル（BLP・Biba・Clark-Wilson など）計28種 | 28 |
| 計算式集 | SLE・ALE・ROSI・RTO/RPO・MTBF など定量指標の計算式まとめ | 5 |
| 罠パターン集 | 試験で引っかかりやすい思考の罠38個と正しい考え方 | 38 |

各カードに「練習問題を解く」ボタンがあり、モーダルで即時フィードバック付きの問題を解ける。

## ローカルで動かす

`git clone` 後にローカルサーバーが必要です（`index.html` を直接ブラウザで開いても動きません）。

### VS Code + LiveServer（推奨）

1. [VS Code](https://code.visualstudio.com/) をインストール
2. LiveServer 拡張機能をインストール
3. `index.html` を右クリック → "Open with Live Server"

### Python

```bash
git clone https://github.com/ak69143/cissp-cat-test.git
cd cissp-cat-test
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### Node.js

```bash
npx serve .
```

## 使い方

1. **模擬試験（CATシミュレーション）**
   - 「試験を開始する」をクリック
   - 試験設定（学習モード / 本番試験モード / カスタム）を選択
   - 100〜150問を解答後、スコアと合否を確認

2. **ドメイン別練習**
   - 「ドメインを選ぶ」から苦手なドメインを選択
   - 難易度フィルターで絞り込み可能
   - 回答後に解説・ヒントを活用

3. **シンキングガイド**
   - トップページから「シンキングガイド」へ
   - 思考パターン・フレームワーク・計算式・罠パターンを参照
   - 各カードの「練習問題を解く」でその場で腕試し
